# 易创（easy-writing）

**纯本地的网文写作桌面软件**：小说写作、码字统计、AI 辅助创作、排行榜风向。作品、设定和写作记录存在你自己的电脑上；无需注册登录，基础写作功能可离线使用。

[English](./README.en.md) · [下载安装](#下载安装) · [下一步计划](#下一步计划) · [商业合作](#商业合作与联系)

> 由长期线上运营的写作平台客户端改造而来，编辑器、自动保存、章节管理都经过真实网文作者的日常使用打磨。适合起点、番茄、七猫、晋江等平台的作者，也适合任何想把稿子攥在自己手里的写作者。

## 为什么选它

- **数据在你手里**：作品、设定、码字记录全部存本机（桌面版是一个 SQLite 数据库文件），支持定时自动备份成 txt + json，随时整本导出。
- **AI 用你自己的钥匙（BYOK）**：可配置 DeepSeek、通义千问、智谱、Kimi、OpenAI 等模型，以及多数提供 OpenAI 兼容接口的服务。API Key 保存在本机，请求时从你的电脑直连所配置的模型服务商。Ollama、LM Studio 等本地部署模型同样支持——API Key 留空即可。
- **提示词全开放**：所有 AI 提示词是本机的 md 文件，界面里可视化改，或者直接改文件，连每个场景的采样温度都能调。
- **免费且开源**：AGPL-3.0 协议，代码全公开。

## 功能

### 写作

- **写作台**：富文本编辑器（TipTap），卷/章目录树、拖拽排序、全书搜索、查找替换
  - 边写边存（160ms 本地落盘 + 关窗快照），异常退出重开即恢复
  - 每章自动保留历史版本，随时回看与恢复
  - 敏感词检测（本地词库可自定义）、打字音效、专注模式、自爆挑战
- **参考资料五件套**：大纲、角色（含关系图画布）、设定、时间线、故事线（思维导图画布）
- **书架**：多作品管理、分组、封面、TXT/JSON 导入导出、回收站
- **码字统计**：今日字数、趋势图、码字日历、连续天数、每日目标；手写与 AI 产出分开记账
- **灵感速记**：首页快记 + 素材库 + 写作台面板，一份数据三处可用

### 写作体验与个性化

- **沉浸式打字反馈**：支持青轴机械键、茶轴机械键、老式打字机、枪声、狗狗汪叫等按键音效，也可完全静音
- **光标处视觉特效**：每次输入可触发挥毫泼墨、墨纹涟漪、云烟缭绕、真实烈焰或文字鼓励，不喜欢动效可一键关闭
- **编辑器自由排版**：可调整字体、粗细、颜色、字号、行高、正文宽度、段间空行、对齐方式与网格线样式
- **四套主题与背景**：内置无界通透、古韵信笺、森系护眼、暗夜水墨四套主题，附带 8 张背景图，也可使用自己的图片作为写作背景
- **专注与阅读预览**：支持全屏写作、停止输入倒计时的“自爆挑战”，以及与正文同步滚动的手机阅读预览

### AI 辅助（需自备 API Key）

- **划词 AI 工具**：选中文字一键润色 / 扩写 / 纠错 / 自定义指令，改完可采纳可废弃
- **续写补全**：快捷键整拍续写（流式进正文）+ 打字时的幽灵字建议（Tab 采纳）
- **妙笔对话**：右栏 AI 顾问，剧情 / 人设 / 设定随时聊，会话历史本地保存
- **工作流一键建书**：灵感 → 大纲 → 设定 → 建书 → 逐章自动生文，断点可续
- **竞品拆书**：TXT 整本导入，逐章拆解节奏与卖点，黄金三章深析 + 全书报告
- **取名器 / 简介生成 / AI 封面**：人名地名功法批量起，简介按平台风格生成
- **AI 调用账本**：每次调用的场景、字数、Token、成败原因全记录

### 榜单风向（桌面版）

内置爬虫用**你自己的网络**抓各站排行榜（起点 / 番茄 / 七猫等 80+ 源），数据只存本机；趋势分析、标签风向、CSV 导出、AI 解读。

## 下载安装

安装包发布后，可在 [Releases](https://github.com/yilujian/easy-writing/releases) 页面下载：

- **macOS**：下载 `.dmg`。当你确认安装包来自本仓库时，若首次打开提示“已损坏/无法验证开发者”，可在终端执行 `xattr -cr /Applications/易创.app` 后再尝试（应用目前未做苹果签名公证）。
- **Windows**：下载 `.exe` 安装程序。SmartScreen 若拦截，点"更多信息 → 仍要运行"。

应用启动后会自动检查新版本（每天最多一次，只查 GitHub 公开接口），有新版会弹通知，点开即达下载页。

## 快速上手

1. 装好打开，「新建作品」写书名建书，直接开写——写作功能不需要任何配置。
2. 要用 AI：侧栏「模型管理」→ 选服务商预设（如 DeepSeek）→ 填入你自己的 API Key → 测试连接 → 保存，再把它设为默认模型即可。
3. 提示词不合口味：侧栏「提示词管理」里每个场景都能改，恢复默认随时可点。

## 数据存在哪里

- **桌面版**：应用数据目录下的 SQLite 数据库；自动备份（txt+json）默认在「文稿」目录；提示词 md 文件在「文稿/易创提示词」。
- **浏览器模式**（开发预览用）：IndexedDB + localStorage，清浏览器数据前请先导出作品。

## 开发

```bash
pnpm install
pnpm dev        # 浏览器开发模式（端口 6789）
pnpm check      # 类型检查 + Lint；有本地测试文件时一并运行
pnpm build      # 构建 Web 产物
```

桌面端（Tauri 2）：需要先安装 [Rust](https://rustup.rs/)，然后 `pnpm dev:desktop` 调试、`pnpm tauri build` 打包。

首次使用 Agent 开发环境，先执行 `pnpm --dir agent-pi setup`。打包会自动准备目标平台的 Pi 和 Node 运行环境，安装包内置这些文件。支持 `universal-apple-darwin`、`x86_64-pc-windows-msvc` 和 `x86_64-unknown-linux-gnu`；通过 Tauri 的 `--target` 指定。Node 下载有固定版本和 SHA-256 校验，构建机需要能访问 nodejs.org。

技术栈：Vue 3 + TypeScript + Vite + Pinia + Element Plus + TipTap 3 + Tauri 2。

## 常见问题

**Q：AI 功能要花钱吗？**
软件本身免费。AI 费用由你配置的模型服务商按实际用量收取。

**Q：我的 API Key 安全吗？**
Key 保存在你的本机配置中。调用 AI 时，Key 和请求内容会从你的电脑直接发送给你所配置的模型服务商。

**Q：为什么榜单功能在浏览器里用不了？**
爬虫需要桌面版的系统能力。桌面版里用你自己的网络抓取，数据只存本机。

**Q：换电脑怎么迁数据？**
书架里整本导出 JSON（含参考资料），新电脑导入即可；或直接拷贝应用数据目录。

**Q：DeepSeek V4、千问这类会"思考"的模型，建书大纲报错或者特别慢？**
这类模型的思考过程会占用输出上限。模型管理里每个模型都有"思考模式"：选"关闭"最快最稳，结构化任务不需要思考；想开着就把"最大输出 Tokens"调到 32768 以上。各家关思考的参数不同，软件已内置 DeepSeek、智谱、火山方舟、千问、硅基流动、OpenRouter、Gemini、Ollama 的写法，其他渠道可在"额外请求参数"里自填。

**Q：本地部署的模型（Ollama、LM Studio 等）连不上，报"没有访问权限"？**
API Key 留空即可，不用填。若仍报 403，多半是本地服务按请求来源拦截了桌面端。桌面版现已不再附带来源信息，请更新到最新版；旧版本可临时给 Ollama 设置环境变量 `OLLAMA_ORIGINS=*` 后重启 Ollama，其他服务把 `http://tauri.localhost` 和 `tauri://localhost` 加进放行名单。
