# 故事展开参考

仅在作者本轮要求完善构思、人物、冲突或开篇方案时使用。

## 构思时想通的六件事

下面是按需要使用的判断依据，不是固定问答顺序，也不要求每次输出六栏。

### 故事看点

说清楚“什么样的人处于什么情境，凭什么产生值得看的故事”。题材标签帮助定位，但不能代替具体创意。差异可以来自人物选择、关系、机制或事件后果，不能只堆多个热门标签。

### 读者期待

说明读者将期待看到什么，以及故事如何逐步给出回报：翻盘、成长、关系变化、真相揭露、探索或日常生活的满足都可以。建立与题材相符的体验，不把所有故事都改成打脸升级文。

### 主角行动

把人物目标与处境连起来：想得到或守住什么，为什么会开始行动，哪些选择体现其性格。重要配角有自己的诉求，与主角形成能推动事件的关系；不只写形容词、身份标签和外貌档案。

### 核心冲突与规则

明确阻碍来自哪里，主角会采取什么行动，行动为什么有效或受限。能力、信息、专业知识、身份和关系都可以成为优势；有金手指时说明它怎样参与剧情及适用条件，没有时不强行增加。作者要求无敌、轻松或其他特定体验时，不机械添加代价或弱点。

### 后续展开

沿选定构思推演开局之后的几个事件，检查它们怎样由前面的行动、结果或关系变化引出。第一次展示结束后，还应有不同的问题、选择与回报，避免只换对手、重复同一种胜利。

长篇关注能够持续变化的目标与情节；短篇关注核心矛盾怎样走向结尾。推演用于补足构思，不自动扩写为全部章节细纲；不能用“不断升级、揭开更大阴谋”代替具体的承接关系。

### 开篇落地

选择能体现本书看点的具体事件，说明主角当前目标、阻碍、行动、第一次结果和下一步期待。需要爽感时，指出反击带来的实际收益、认可、关系或局势变化，不能只写旁人震惊。需要悬念时，说明读者在等什么、何时推进或兑现，避免只堆未解问题。

开篇长度与结构服从作者要求和故事需要；不统一规定前三章分工、多少字内必须出现冲突、每章必须有钩子。用户只要开篇方案时，不直接生成正文。

## 让设定与情节一起成形

- 围绕当前故事需要补人物、世界规则、关系和阶段情节，允许在推演中相互调整。关键规则改变时，检查受影响的已有构思并说明取舍。
- 没有要求详细大纲时，先做到整体方向和开篇阶段足够清楚。作者要求完整大纲、卷纲、力量体系或群像时，再展开相应部分，不预制整套无关设定。
- 参考书与样本提供方法启发，人物、专有设定和事件不直接搬入新书。没有参考资料也能构思，不强制先拆书、蒸馏或查询公共示例库。
