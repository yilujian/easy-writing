# 书名与简介方法

用于生成或优化小说书名、简介。沿用作者已经确定的故事和定位；只改其中一项时只交付该项。具体步骤按信息是否齐全决定，不要求作者逐项确认，也不要求出现某句固定话才接受委托。

## 选择真正相关的榜单

仅在作者需要市场参考时，用 list_rankings 查看目录，再按查询条件读取匹配平台、读者、题材及榜种的已有快照。新书策划可先比较同类新书榜，再参考同类阅读榜；新书榜不等于新人作者榜。作者指定的来源优先。

- 平台负责解析来源编号。根据目录中的平台、频道、分类和榜种表达查询条件；多个匹配时选具体条件，不将综合来源擅自当成目标频道。
- 先比较足以看出表达差异的一小组作品，按需要补充，不设必须凑满的数量。不要只模仿第一名，不把同一本书在不同榜单出现算作多个案例。
- 记录所用来源、快照日期、作品名称和链接。同一方向已有有效参考时可复用；作者换平台、读者或故事方向后重新判断适用性。
- 榜单为空、日期不合需要或缺少对应频道时，说明具体缺口。仅在作者要求新数据时刷新，并遵守工具确认；不为补资料自行访问未开放的服务。
- 短篇没有合适资料时，不直接套用长篇榜；跨题材借鉴需说明只是参考某种表达方式。作者未限定平台时可给不同取向的建议，但不能把混合样本当成某个平台的统一规律。

## 同时看书名和简介

根据本次任务观察：书名透露了什么看点，哪些具体词或关系使它有辨识度，简介开头怎样承接，哪个行动或机制展示差异，以及结尾留下什么阅读期待。留意这组作品中重复的表达，避免候选只是同一模板换词。

将故事内容与作者宣传分开。奖项、改编、出版、前作成绩、评分解释和更新承诺不属于可以搬给新书的故事写法。只有书名、缺少简介时，只判断命名方式，不编造原书情节。

榜单能够展示已有作品怎样表达，不能证明某个名字导致上榜。短书名与长书名都可以参考，不把成熟作品的作者名气或宣传条件推定为新作者也具备。

## 从本书事实产生书名

先找作者已经确定、最值得放进名字的内容：特殊行动、明确机制、人物关系、处境或重要意象。抽象的“很强、很爽、很反套路”不能替代具体看点。故事差异不足时指出缺口并提出构思建议，不通过擅自增加系统、能力或关系让标题显得热闹。

按本书需要选择表达方向，不要求每次凑齐：

| 方向 | 要突出什么 |
| --- | --- |
| 看点直述 | 题材、能力或事件机制，让读者容易理解会看到什么 |
| 人物与选择 | 某种身份或处境中的人作出了什么独特选择 |
| 关系与情绪 | 有辨识度的关系变化、冲突与情感取向 |
| 意象与悬念 | 贯穿故事的物件、场所、期限或待解问题，由简介补足具体内容 |

需要比较时给少量有实质差别的候选，各附一句理由与取舍；只要一个或委托定名时直接推荐，不为走流程强迫再选一次。书名长短和语气服从作者偏好及可核查的平台限制，不固定使用某种句式，也不把所有标签塞进一个名字。

保留作者已选书名。实际读取的样本中有同名或高度近似表达时提醒并调整；样本中未见不能说成完成了全网查重。没有可靠资料时不声称已核实平台字数上限。

## 用简介展开阅读期待

简介与书名相互补充：让目标读者理解故事的具体吸引力，并感受到它的语气。不要把书名重复几遍，也不要把人物档案和整本大纲压成一段说明。

可以从具体困境、人物关系、特殊规则或一次行动进入，再补必要的主角处境、核心差异和后续期待。适合时用一小段事件或对白展示看点，不固定段落数量，不要求所有简介都以问句、系统弹窗或宏大预告收尾。

- 机制型故事可展示独特用法；悬疑可给异常和待解问题；关系型故事可呈现关系变化；日常故事可体现生活愿望与相处趣味。由实际故事选择，不仅凭频道标签决定。
- 只使用已确定的能力、身份、关系和情节承诺，保留作者要求隐藏的谜底。若新的表达需要改变故事，将改变作为建议，不静默写成事实。
- 重要阅读取向按作者要求写清，例如情感方向或是否有感情线；不自行推定，也不堆与作品无关的热门标签。
- 不借用原作的荣誉或宣传文案，不用“简介无力，请看正文”代替介绍看点，不凭模型判断声称作品独创、必火或高点击。
- 简介的人称是宣传表达，不决定正文视角；篇幅按请求和可核查的限制控制，不预设统一字数。

## 成套交付和保存

完整请求可以一次交付少量“书名、对应简介、推荐理由”，也可以沿作者选择先定名字再打磨简介。作者已有明确意见时直接处理，只有核心冲突或必要缺口才询问。

参考依据用简短说明交代平台、榜单日期、相关作品和借鉴方式，不把完整研究报告夹进简介。作者只要结果时优先展示候选，仍应避免冒充已做过的查榜或效果验证。

交付前核对书名和简介是否符合本书事实、作者定位及本次范围，候选之间是否有实际区别。只核对这些可说明的依据，不打“爆款分”，不启动自动审稿重写循环。

新书将选定或作者委托确定的版本映射到 title、intro，实际采用继续走平台确认；其他备选不要合并塞进字段。现有工具的 book 类型只支持创建，优化已有作品书名或简介时先读取真实资料，交付修改建议，不用新建作品替代修改，也不声称已写回原书。

## 方法来源

本方法结合易创本机榜单的书名、简介对照与已讨论方案整理。官方资料提供表达原则，不是运行时必须联网阅读的步骤：

- [17K 书名简介课程](https://author.17k.com/ck/author/article/content/219.html)：参考向读者清楚传达具体看点的原则，不将其中对书名长度的建议作为通用规定。
- [番茄作品包装课程](https://fanqienovel.com/writer/zone/article/7480101551080489022)：参考元素呼应、情绪一致与信息互补；实际写法服从作者的故事和读者定位。
