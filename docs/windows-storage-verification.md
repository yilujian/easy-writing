# Windows 存储升级与恢复验收

完成日期：2026-10-09；开始日期：2026-10-08。当前 main 工作区，未提交、未发布。

## 环境与隔离

- Parallels Desktop 26.4，Windows 11 Pro `10.0.26200` ARM64；运行 Windows x64 程序，属于 Windows x64 兼容环境验证。
- 用 `v1.1.0` 标签源码构建旧版，用当前工作区构建新版。测试版本依次为 `1.1.0`、`1.1.1-audit.0`、修复后的 `1.1.1-audit.1`，正式项目版本号未修改。
- 安装包为实际 NSIS 安装包，在虚拟机中安装及覆盖升级，退出码均为 0；跨平台构建使用 cargo-xwin。
- 两版统一使用独立标识 `com.yichuang.writing.win-storage-audit` 和独立进程名 `ew-storage-audit.exe`，避免覆盖或停止原有正式程序。
- 测试源码副本仅另设应用名、标识、测试版本、二进制名，以及提示词/备份目录。正文数据库位于该独立标识的 Roaming 目录；提示词和备份位于 `%LOCALAPPDATA%\EasyWritingStorageAudit`。
- 正式版进程保持运行，文件操作限定在测试目录。没有修改系统代理、安全设置或生产更新通道。

## 发现并修复

旧模式中的非法封面可进入备份包，恢复时才因图片编码失败中断。已在主分支修复：备份与恢复共用纯解析器，对无法解析的封面在传输副本中跳过并明确提示，原数据库/原包保留。导入不再重用界面缓存的坏封面引用。

重新构建 `1.1.1-audit.1` 并覆盖安装后，真实恢复此前生成的坏封面 ZIP 成功。界面报告作品 1 本、章节 1 章、历史 3 条、提示词 14 个，并明确提示已跳过损坏封面；数据库核对正文、排版、标题、参考资料和历史通过。
