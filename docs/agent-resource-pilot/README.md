# 写作资源首批验收材料

状态：待人工核对。未进入默认推荐；未完成资源效果验收。

本批暂选“都市职场”，围绕对白僵硬、反击无力、解释过多三个问题准备了 12 条完整场景。它们是本次开发生成的原创示例，不是合作作者提供的样稿，也不是已经证明有效的写作规律。每条均保留前情、行动、结果、适用条件和不适用情况。

## 文件

- `resources.json`：可从 Agent → 写作资源 → 导入资源包导入。导入统一为待核对；不会接受包里自称的人工推荐状态，也不会覆盖已存在条目。
- `source-leads.json`：官方资料入口及核查日期。仅保留链接，未复制原文；内容负责人可据此补充后续授权材料。
- `tasks.json`：6 个调整任务和 6 个保留任务，资源分配是待人工确认的初稿。
- `selection-scenarios.json`：20 个选择场景。AI 拟定的答案不能作为正确性验收，需内容负责人标注适合、不适合和无需资源。

## 人工需要确认什么

1. 试点题材与这三个问题是否符合当前用户。
2. 逐条检查场景是否完整、说明是否曲解、是否还缺重要前提；决定保留、修改或搁置。
3. 确认测试任务与适用资源的对应关系，再固定模型、设置和预算做 A/B/C 对照：不加资源、仅样本、样本加说明。每组每题生成两次，共 72 份，全部保留。
4. 评审者独立阅读隐藏组别的输出，记录具体理由、修改成本及事实问题，允许“无明显差别”“都不好”。只有结果支持其范围且没有未处理事实问题，才在资源管理页设为可推荐。

本次没有虚构内容负责人、读者评审、授权或有效结论。读取日志只说明材料实际交给了模型，不能证明模型遵循了方法或提高了写作质量。

