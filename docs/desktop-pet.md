# 桌面桌宠

入口：设置中心 → 桌宠。首次默认关闭，开启后显示独立的透明、无边框置顶窗口。

- 8 个已确认形象；标准大小 200，可选 160 / 260。
- 左键拖动到桌面任意位置，位置保存在应用配置目录；屏幕布局变化后重新限制到可见工作区。
- 右键菜单隐藏或打开设置。隐藏后停止动画，从设置中心重新开启。
- 主窗口最小化时桌宠继续显示；平台退出时统一销毁。
- 气泡与菜单沿用 `themes.scss` 四套主题变量。专注模式和系统减少动态效果偏好会停止循环动作。
- 桌宠不读取数据库或模型密钥，不重复启动业务 Store、备份服务、Agent 执行器。

## 结构

- `src-tauri/src/desktop_pet.rs`：唯一窗口、偏好与位置、消息转发、透明空白区域鼠标穿透。
- `src/desktop-pet/PetWindow.vue`：轻量窗口、动作播放、拖动、右键菜单。
- `src/desktop-pet/coordinator.ts`：主窗口汇总真实写作、AI、Pi 对话和长任务状态。
- `src/desktop-pet/events.ts`：通用 AI 请求与导出的旁路反馈，不等待桌宠，不改业务返回值。
- `src/views/SettingsCenter/panes/PetPane.vue`：即时生效的设置分区。
- `public/desktop-pets`：已确认原图与 5×4 动作图集；行列边界在 `sheets.json` 中。

## 状态口径

码字状态取现有写作计划 Store 的真实输入时间。手写/AI 字数、目标及统计模式取现有账本，25/50/75/100% 节点分开计算；跨多个节点只展示最高一个，启动不补播旧达标。

AI 成功、失败、主动取消分别结束状态。候选稿保留待确认状态，不能表示正文已保存。前台会话等待确认优先；后台任务不持续打断码字；存储异常优先提醒。

## 平台说明

macOS 透明窗口需要 Tauri 的 `macos-private-api` 与 `macOSPrivateApi`。此方案适用于项目当前直接分发方式；Mac App Store 上架需要另行评估。Windows/Linux 的窗口层级、拖动和鼠标穿透仍需各自实机验收。

浏览器开发预览可使用 `?desktopPetPreview=1` 查看独立画布；它不具备系统桌面窗口能力。此入口仅存在于开发构建。
